# STATE V6.1 — The Threshold

Open `index.html` in a modern browser.

This prototype is intentionally focused on the first 90 seconds of STATE and one finite return-to-life journey.

## Included

- state constellation arrival;
- recognition before recommendation;
- responsive Living Sanctuary house;
- Body, Mind and Relationships room logic;
- one art-directed formula vessel;
- Feel / Understand / Practise layers;
- 60-second CALM 10 guided exhale preview;
- one-minute action thresholds for FOCUS, WALK, COURAGE, CONNECT and RELEASE;
- local-only session records;
- explicit open-door ending;
- reduced-motion support.

## Boundaries

This is a design and interaction prototype. It is not medical care, diagnosis, crisis support, scientific proof or a live brain measurement.
