# V4 Product Spec — FOCUS 25

## Product promise

Move one visible outcome from resistance into motion in a finite 25-minute ritual.

## Primary user journey

1. Choose full dose or 60-second preview.
2. State one visible outcome.
3. Record resistance and energy.
4. Remove three environmental exits.
5. Enter a distraction-free timer room.
6. Complete, pause or exit honestly.
7. Record outcome, resistance and next-hour score.
8. Receive a local proof receipt.
9. Leave the product.

## Core metric

> Did this experience improve the next hour of the person’s actual life?

Supporting metrics:
- completion status;
- outcome achieved / partly / not achieved;
- resistance change;
- session duration;
- voluntary reuse;
- qualitative friction notes.

## Privacy

- No account required.
- Local storage by default.
- Export is voluntary.
- No third-party analytics in the initial beta.
- The local proof receipt is not an NFT, financial instrument or public identity claim.

## Acceptance criteria for the first V4 slice

- Complete flow works from landing through saved receipt.
- Preview and 25-minute modes exist.
- Timer can pause, complete early or exit honestly.
- Local dashboard updates from saved sessions.
- Results can be exported as JSON.
- Mobile layout is usable.
- Reduced-motion preference is respected.
