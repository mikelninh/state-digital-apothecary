# V5 Experience Specification — The Human Starter Pack

## Objective

Turn the V5 concept store into five finite, distinct and testable digital rituals. The collection must feel coherent as one brand while each formula uses a different human mechanism.

## Shared experience architecture

1. **Arrive** — name what is actually happening.
2. **Prepare** — reduce environmental friction.
3. **Dose** — enter one finite, state-specific ritual.
4. **Return** — leave the product without reward theatre.
5. **Reflect** — record whether the next hour became more usable.

All sessions remain local by default. No account, streak, public profile or hidden analytics is required for the prototype.

## Formula mechanisms

### FOCUS 25
- Mechanism: implementation intention + distraction removal + bounded work interval.
- Desired outcome: one visible task moved forward.
- Visual language: a narrow beam cutting through noise.

### CALM 10
- Mechanism: longer exhale + sensory orientation + lowered decision demand.
- Desired outcome: intensity reduced enough to choose the next action.
- Visual language: a slow breathing field and soft horizon.

### COURAGE 01
- Mechanism: name fear + shrink action + cross a visible threshold.
- Desired outcome: one avoided action attempted while discomfort remains.
- Visual language: a threshold line and forward pulse.

### CONNECTION 02
- Mechanism: consent + two honest questions + uninterrupted listening.
- Desired outcome: one safer, more genuine exchange.
- Visual language: two circles becoming a shared field.

### PURPOSE 01
- Mechanism: choose a beneficiary + define a bounded useful act + complete it.
- Desired outcome: care converted into contribution.
- Visual language: one point creating outward ripples.

## Measurement

Each formula records only what is needed for product learning:

- formula and mode;
- completion or honest exit;
- before and after state rating;
- outcome achieved: yes, partly or no;
- next-hour score from 1–5;
- optional private note.

## Design rules

- Full-screen dose room, visually quieter than the store.
- One dominant action per step.
- No confetti, badges, streaks or urgency.
- Distinct formula motion, but shared typography and product grammar.
- Reduced-motion mode must preserve meaning.
- The ending always points back to real life.

## Release gate

V5 is not commercially ready merely because the shop looks convincing. Before enabling payment:

- all five flows work on mobile and desktop;
- session storage and honest exit work reliably;
- each formula has at least five observed tests;
- the buy-one-fund-one ledger is reconciled rather than simulated;
- users understand that STATE is not medical treatment or crisis support.
